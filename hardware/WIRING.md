# Распиновка тестового макета

Номера обозначают GPIO, а не порядковые номера контактов платы. Соответствует сохранённой прошивке.

| Компонент | Контакт | Подключение |
|---|---|---|
| SW1–SW6 | Первый контакт | GPIO1, 2, 4, 5, 6, 7 соответственно |
| SW1–SW6 | Второй контакт | GND |
| Энкодер | CLK / DT / SW | GPIO8 / GPIO9 / GPIO10 |
| Модуль энкодера | VCC / GND | 3V3 / GND |
| OLED | SDA / SCL | GPIO11 / GPIO12 |
| OLED | VCC / GND | 3V3 / GND |
| WS2812 | DIN | GPIO13 через 330 Ω |
| WS2812 | VCC / GND | USB/VBUS 5 V / GND |

Все земли общие. Клавиши и кнопка энкодера используют INPUT_PULLUP, нажатие замыкает GPIO на GND. Контакты LED свитчей не относятся к контактам механизма нажатия. Для голого энкодера общий контакт A/B идёт на GND; питание VCC относится к модулю.

GPIO19/20 оставлены для native USB. Внешняя RGB-цепочка содержит 4 LED. OLED ищется на 0x3C/0x3D, в отчёте загрузки обнаружен 0x3C.

Полная инструкция и диагностика: [firmware/README.md](../firmware/README.md).
