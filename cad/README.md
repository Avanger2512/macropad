# Mechanical assets

The current [compact C4 revision](compact/c4/README.md) corrects the first C3
print: tighter MX apertures, OLED window shifted toward the encoder to match
measured glass offset, integral upper OLED glue pins, and ESP slots15mm apart.
It retains the C3 layout. STL exports include upper shell, flat bottom and an
MX fit sample. Earlier revisions and printed Fusion V9 remain preserved.

The native enclosure prototype and fit-print sequence are documented in [fusion/README.md](fusion/README.md). Its STEP/F3D exports are separate from the existing switch-mount assets below.

The original files were moved here from the project root. Model geometry is unchanged; the 3MF slicer profile name was translated into English.

| File | Intended purpose based on its name |
|---|---|
| [MX.stl](MX.stl) | Model for an MX switch |
| [choc.stl](choc.stl) | Model for the alternative Choc switch type |
| [hotswap_mx__with_wing.stl](hotswap_mx__with_wing.stl) | MX hot-swap mount with side wings |
| [whotswap-MX-v2.3mf](whotswap-MX-v2.3mf) | 3MF project for MX hot-swap mounting |

Purposes in this table are inferred from filenames. Geometry, switch fit, and print profiles of these existing assets were not checked during repository preparation. They do not constitute a complete enclosure kit; the new Fusion enclosure draft still requires physical fit and mounting work.

The model authors, original source links, and licenses have not been established. The firmware license does not change the distribution terms of these files. Their provenance and distribution terms remain unresolved.
